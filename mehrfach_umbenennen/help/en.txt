<b>How it works</b>

At the top you build the new name from <b>building blocks</b>. Clicking a button inserts the block at the cursor position. You can also type ordinary text around it.

<b>File name</b>
  <tt>[N]</tt>        the old name (without extension)
  <tt>[N2-5]</tt>     only characters 2 to 5 of the old name
  <tt>[N3-]</tt>      from character 3 to the end
  <tt>[N-4]</tt>      the last 4 characters
  The <b>[N#-#] Part</b> button opens a window where you simply select the part with the mouse.

<b>Extension</b>
  <tt>[E]</tt>        the old extension (e.g. jpg). Leave the field empty = no extension.

<b>Counter, date, time</b>
  <tt>[C]</tt>        running counter – set start, step and digits on the right
  <tt>[YMD]</tt>      the file's modification date, e.g. 2026-10-03
  <tt>[Y] [M] [D]</tt>  year, month, day on their own
  <tt>[hms]</tt>      modification time, e.g. 14-05-09
  <tt>[P]</tt>        name of the folder the file is in

<b>Examples</b>
  <tt>Holiday [C]</tt> with 3 digits  →  Holiday 001.jpg, Holiday 002.jpg …
  <tt>[YMD] [N]</tt>  →  2026-10-03 Beach.jpg
  <tt>[N1-7]</tt>  →  keep only the first 7 characters

<b>Search &amp; Replace</b> is applied after the mask. “Regular expression” allows advanced patterns, but you never need it.

<b>Regular expressions</b> – round brackets <tt>( )</tt> in the search text remember a part; <tt>$1</tt>, <tt>$2</tt> … insert it again in the replacement:
  <tt>^(\S+) - (\S+) - (\S+) - (.*)$</tt>  →  <tt>$1-$2.$3.$4</tt>
  K733142 - EN - 1 - - Drawing Object  →  K733142-EN.1.- Drawing Object
  <tt>\S+</tt> = a word without spaces, <tt>.*</tt> = any text, <tt>\d</tt> = a digit, <tt>^</tt> / <tt>$</tt> = start / end.

<b>F2 Load/save settings</b> – saves all fields under a name so you can reuse a complicated setup with two clicks. <b>F2</b> opens the list.

The order of the list sets the counter. Drag rows with the mouse or sort by name or date above.

The preview turns red if a name occurs twice or already exists – then nothing is renamed.
<b>Undo</b> reverts the last renaming, even after restarting the program.

Keyboard: <b>Ctrl+Enter</b> rename, <b>F1</b> help, <b>F2</b> saved settings, <b>Esc</b> close.
